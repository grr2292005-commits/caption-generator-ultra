How to Import Static Transcript
  1. Select the SOURCE CLIP in Project panel (the media file, not just sequence)
  2. Open Window > Text
  3. Open Transcript tab
  4. Click the ... menu
  5. Choose Import > Import Static Transcript
  6. Select the exported JSON file
Important note: Import Static Transcript attaches to the selected source clip. Select the clip first.
