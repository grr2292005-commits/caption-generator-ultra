# Caption Generator ULTRA

## Overview
Caption Generator ULTRA is the experimental, text-based editing development branch of Caption Generator Pro for Adobe Premiere Pro.

## Baseline Features (Inherited from Caption Generator Pro)
- **Local Whisper AI Transcription**: Embedded, fully offline Whisper speech-to-text models (Tiny, Base, Small, Medium, Large-v3).
- **Adobe Premiere Native Integration**: Generates official Adobe Static Transcript format (`.json`) matching Premiere Pro's Text & Transcript schema.
- **Caption Generation & SRT Export**: In-panel review, edit, subtitle creation, and `.srt` export.
- **License & Dependency Manager**: Integrated license validation and Speech Model Manager.
- **No External Cloud Dependencies**: Local Python & FFmpeg bundled runtime.

## Development Objectives
- Text-based editing research and prototyping.
- Advanced timeline synchronization.
- Future text-to-timeline editing workflows while preserving sequence integrity.

## Installation
- Extension Directory: `%APPDATA%\Adobe\CEP\extensions\CaptionGeneratorUltra`
- Bundle ID: `com.captiongenerator.ultra`
- Host: Adobe Premiere Pro
